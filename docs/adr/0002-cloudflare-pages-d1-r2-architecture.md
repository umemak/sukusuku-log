# Cloudflare Pages + D1 + R2 によるサーバーレスエッジ構成

常駐サーバーのインフラ管理コストおよびランニング費用を最小化し、高速な配信とシンプルな運用を実現するため、Cloudflare Pages（Hono）、Cloudflare D1（SQLite）、および Cloudflare R2（オブジェクトストレージ）を中心としたフルマネージド・エッジ構成を採用した。

## Considered Options

- **常駐コンテナ（Node.js / VPS / Docker）+ PostgreSQL**: 常駐プロセスやWebSocketによるリアルタイム通知が容易だが、インフラ維持費と保守運用負荷（OS/DBパッチ、コンテナ監視）が発生する。
- **Firebase / Supabase**: リアルタイム同期（Firestore / Realtime）や認証が組み込まれているが、外部サービスへの依存度が高く、将来的な移行やコスト予測が複雑化しやすい。

## Consequences

- サーバーのプロビジョニングや監視が不要で、GitHub pushをトリガーとした自動マイグレーションおよびエッジデプロイが可能になった。
- 常駐WebSocket接続ができないため、他端末との同期は画面復帰時および20秒間隔の定期ポーリングによって実現している。
- 写真データはR2に格納し、API経由で家族認証を行った上でストリーミング配信するため、プライベートな写真が公開URLで露出するのを防いでいる。
