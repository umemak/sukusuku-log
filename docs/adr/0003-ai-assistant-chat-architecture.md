# AIアシスタントのメンバー別D1永続化とコンテキスト事前注入方式

育児記録の逆引き照会や成長レター生成を行う対話型AIアシスタントにおいて、端末変更時にも対話を引き継ぎつつ家族間のプライバシーを保護するため、チャット履歴を家族共通ではなくメンバー（`member_id`）単位で Cloudflare D1 に永続化し、Gemini API にはサーバー側で直近ログ・集計データをプロンプトに同梱する事前注入方式を採用した。

## Considered Options

- **端末ローカル保持（localStorage）**: サーバー側ストレージを消費せず実装が容易だが、複数端末（スマホとタブレット・PCなど）で作業を引き継ぐことができない。
- **家族共通チャットルーム（家族IDでのD1共有）**: 実装はシンプルだが、パートナーや閲覧専用の祖父母など家族全員の画面に対話履歴がそのまま流れてしまい、各自の自由な質問や試行錯誤がしにくくなる。
- **Gemini Function Calling（動的クエリ呼び出し）**: 多様なクエリに対応できるが、複数ターンの通信が発生し、レスポンス速度の低下と日次API利用枠の急激な消費を招く。

## Consequences

- メンバーは端末を切り替えても自身の過去のやり取りを参照でき、かつ他の家族メンバーに見られることなく安心して質問できる。
- 閲覧者（Viewer）も日次利用枠の範囲内でAIアシスタントを利用でき、孫の様子や成長レターを手元で確認できる。
- サーバー側で直近48時間のログ・当日の集計サマリーを事前に Gemini へ渡すため、1往復のAPI呼び出しで高速かつ安価に応答を返せる。
