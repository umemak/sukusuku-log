# 端末トークンとワンタイム招待コードによる認証

新生児の育児中に片手や暗がりでもストレスなく利用できるよう、一般的なパスワードやOAuthログインを廃止し、初回メール確認、端末ごとのランダムベアラートークン（localStorage保持・DBにはSHA-256ハッシュ保存）、および24時間有効・1回限りの使い捨て招待コードによる認証を採用した。

## Considered Options

- **一般的なID / パスワード認証**: セキュリティの標準だが、育児中のログインセッション切れやパスワード入力・再設定の手間が継続利用の大きな障壁になる。
- **OAuth（Google / Appleログイン）**: パスワード管理は不要になるが、家族メンバー間でアカウントプロバイダが異なる場合（iOSとAndroid、祖父母のGoogle非所持など）に招待のハードルが上がる。
- **固定の家族コード（合言葉）共有**: 初期の運用コストは低いが、一度外部に漏洩した際のリセットや端末別の権限管理・メンバー削除が困難になる。

## Consequences

- ユーザーはログイン画面やパスワード入力に煩わされることなく、URLや招待コードから即座に記録を開始できる。
- メンバーの追加や端末の追加には、必ず既存の記録権限メンバーによる24時間限定の招待コード発行が必要となり、固定コード漏洩のリスクを防止できる。
- 端末のlocalStorageがクリアされた場合、既存の参加中端末から新しい招待コードを発行して再参加する必要がある。
